# Trait System v2 Pointer

This document points to the preserved full trait system document:

**[2026-05-18-m3-trait-system-v2.md](2026-05-18-m3-trait-system-v2.md)**

---

The trait system v2 defines:

- 8 positive traits and 8 negative traits, for 64 valid combinations
- Modifier tuples on the stat model, with no new content paths
- Scoring modifiers, starting value changes, per-event cost adjustments
- Post-GDR balance revision rules for P6 and N6 threshold or gate changes

Trait values require orchestrator approval before modification.

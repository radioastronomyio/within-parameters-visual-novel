# Assets

This directory contains runtime placeholders, sourced audio, concept artwork, UI packs, and asset tracking for Within Parameters. The engine can run with these placeholder assets while production artwork and cutscenes remain open work.

---

## 1. Contents

```

├── audio/                 # Four sourced BGM tracks in OGG format
├── backgrounds/           # Thirteen generated placeholder scene PNGs
├── concept-artwork/       # NightCafe concept drafts and UI mockup

│   ├── scene02/
│   ├── scene03/
│   ├── scene04/
```

## 3. Subdirectories

| Directory | Description |
|-----------|-------------|

| [ui/](ui/) | Empty runtime UI asset directory reserved for later integration |

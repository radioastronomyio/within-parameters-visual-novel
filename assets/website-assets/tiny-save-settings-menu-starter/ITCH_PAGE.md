# Tiny Save / Settings Menu Starter

A tiny drop-in menu starter for web games.

This gives you a working save/settings UI with local save slots, persistent settings, keybinds, and JSON import/export. It is built with plain HTML, CSS, and JavaScript, so it is easy to copy into a jam game, prototype, idle game, RPG, roguelike, or browser project.

## What You Get

- Working save/settings menu demo
- 3 save slots with load, save, delete, quick save, and new run actions
- Persistent settings via localStorage
- Audio, display, gameplay, accessibility, and theme settings
- Rebindable controls
- JSON export/import tools
- Responsive desktop and mobile layout
- No framework
- No build step
- Docs and integration notes

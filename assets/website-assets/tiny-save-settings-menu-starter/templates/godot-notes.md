# Godot Notes

This starter is written for web games, but the state shape maps cleanly to Godot.

Suggested mapping:

- `state.slots` -> save files in `user://`
- `state.settings` -> `ConfigFile`
- `state.controls` -> `InputMap`
- export/import -> JSON string backup

Use the HTML demo as a UI reference if you rebuild the menu in Godot Control nodes.

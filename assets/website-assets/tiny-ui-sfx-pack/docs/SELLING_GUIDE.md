# Selling Guide

## Positioning

Sell this as a cheap, finished utility pack for creators who need quick UI polish without hunting through giant sound libraries.

Good titles:

- Tiny UI SFX Pack
- 64 Game UI Sound Effects
- Menu Clicks, Hovers and Alerts SFX Pack

## Price

Recommended launch price: `$1.99`.

Sale price: `$0.99-$1.49`.

Raise to `$2.99-$3.99` if you add OGG exports, more sounds, or engine import presets.

## Upgrade ideas

- OGG exports.
- 96 or 128 total sounds.
- Retro, soft, sci-fi, and horror subfolders.
- Unity and Godot import presets.
- A small “sound picker” web tool that copies file names.
